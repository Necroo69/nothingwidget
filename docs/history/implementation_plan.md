# Migration & Integration Plan: NothingWidget (Repo 2 Base)

Based on your feedback, we will completely abandon the original Repo 1 codebase as our foundation and transition the workspace to **Repo 2** (the Google AI Studio design). 

We will make Repo 2 the main project in this folder, and then selectively integrate the working background widget logic (from the old Repo 1) so that the beautiful new widgets actually function.

---

## 1. Actionable Steps

### Phase 1: Workspace Replacement
We will replace the current workspace contents with the AI Studio repository.
1. **Backup Functional Logic**: Temporarily save `BootReceiver.kt`, `ClockUpdater.kt`, and the Intent Filters from the old Repo 1.
2. **Clear Workspace**: Delete the `app`, `gradle`, and configuration files from the root of Repo 1.
3. **Promote Repo 2**: Move all contents from `studio_repo` into the root of your workspace. 
   - *Result*: Your project is now 100% the AI Studio codebase.

### Phase 2: Widget Logic Integration
Now that Repo 2 is the main project, we will inject the "working" widget logic into it.
1. **Port Background Updaters**:
   - Introduce `ClockUpdater.kt` (AlarmManager) and `BootReceiver.kt` into the new `com.example` architecture.
   - Register `BootReceiver` in the new `AndroidManifest.xml`.
2. **Upgrade Stubbed Providers**:
   - Update `NothingClockWidgetProvider` so that it is triggered by the `AlarmManager` every minute.
   - Update `NothingBatteryWidgetProvider` in the manifest to listen for `android.intent.action.BATTERY_CHANGED`.
3. **Bridge UI Settings to Widgets**: 
   - Connect the new `WidgetCustomizerScreen` to the Room Database (or SharedPreferences) so that when a user customizes a widget, it immediately updates the live widget using `AppWidgetManager.updateAppWidget()`.

### Phase 3: Cleanup
1. **Package Name Refactor** (Optional): Decide if we want to keep the package name as `com.aistudio.nothingwidgets.xkmqpz` / `com.example`, or rename it back to `com.sritam.nothingwidget`.
2. **Remove `studio_repo`**: Delete the temporary cloned folder to keep the workspace clean.
